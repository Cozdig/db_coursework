# HR Analytics Database Project
## Описание
Система для сбора и анализа данных о вакансиях с hh.ru. Автоматически получает данные через API, сохраняет в PostgreSQL и предоставляет аналитику.


## Установка
Установите зависимости: pip install -r requirements.txt

Создайте файл .env на основе .env.example

Запустите: python main.py

## Функциональность
Автоматическое создание БД и таблиц

Сбор данных о 10 компаниях и их вакансиях

Поиск вакансий по ключевым словам

Анализ зарплат (средняя, выше средней)

Полная статистика по компаниям и вакансиям

# Документация проекта
## config.py

#### db_config: Настройки подключения к PostgreSQL

#### companies: Список компаний для мониторинга (10 компаний)

#### hh_api: Базовый URL API hh.ru

## create_db.py

#### create_db(): Создает БД если не существует

#### get_db_connection(): Возвращает соединение с БД

#### create_tables(): Создает таблицы employers и vacancies

#### add_employer(): Добавляет работодателя в БД

#### add_vacancy(): Добавляет вакансию в БД

#### db_ready(): Основная функция инициализации БД

## db_manager.py

### Класс DBManager:
#### get_companies_and_vacancies_count(): Компании и кол-во вакансий

#### get_all_vacancies(): Все вакансии с информацией

#### get_avg_salary(): Средняя зарплата

#### get_vacancies_with_higher_salary(): Вакансии с зарплатой выше средней

#### get_vacancies_with_keyword(): Поиск вакансий по ключевому слову

## external_api.py

#### get_employers(): Данные о компаниях

#### get_vacancies(): Данные о вакансиях

#### employers_info(): Форматированные данные компаний

#### vacancies_info(): Форматированные данные вакансий

## interface.py

#### main_interface(): Главное меню

#### print_employers_and_vacancies(): Вывод компаний

#### print_all_vacancies(): Вывод всех вакансий

#### print_avg_salary(): Вывод средней зарплаты

#### print_vacancies_with_higher_salary(): Вакансии с высокой зарплатой

#### ask_keyword(): Поиск по ключевому слову

## main.py

#### main(): Объединяет весь функционал, запускает интерфейс

## Использование
Программа предлагает меню:

Список компаний и количество вакансий

Все вакансии с детальной информацией

Средняя зарплата

Вакансии с зарплатой выше средней

Поиск вакансий по ключевому слову

Выход
